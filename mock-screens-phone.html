Screen A — Login
First-Time Sign In
Shown only on first launch or after session expiry. The user enters their Acumatica site URL and credentials. The app authenticates via Acumatica's OAuth 2.0 endpoint. On success, a session token is stored on the device and the user is not prompted again until the token expires.
Sign In Securely Submits credentials to Acumatica OAuth endpoint. On success, navigates to the Queue screen. On failure, displays an inline error message with the reason returned by Acumatica.

Screen B — Queue
Pending Capture Worklist
Shown after login. Lists all Sales Orders that have one or more stages with zero photos captured. Sorted by urgency: all-pending orders first, then partial. The colored dot indicates the current active stage. Tapping any order opens it directly at the pending stage.
Order Row Tap Opens the SO on the Capture screen at the first incomplete stage. No QR code required from this entry point.
Scan QR Code Opens the device camera in QR scan mode. Scans the code on the desktop Acumatica screen and loads that specific order.
Queue Tab Returns to this worklist from anywhere in the app.
Search SO Tab Opens a manual search field to find an order by number or customer name.
Screen C
Cancel
Scan the QR code on the Sales Order screen
Hold your phone steady over the QR code shown on the Acumatica Sales Order screen. The order will load automatically.
Screen C — QR Scan
Scanning the Sales Order QR Code
Triggered from the Queue screen or the Scan New Order button. The device camera opens in QR scan mode. The user points it at the QR code displayed in the Acumatica SO header. On successful scan, the app decodes the SO number and current active stage from the URL and navigates directly to that order's capture screen.
Auto Scan No button press needed. The moment a valid BMES QR code is detected, the app navigates automatically. Invalid QR codes are ignored.
Cancel Closes the camera and returns to the previous screen without loading any order.

Screen H — Photo Detail
View, Annotate, Delete, or Retake a Photo
Opened by tapping any thumbnail. Shows the full-size image with all metadata. The Notes field is the only editable element. Notes entered here are written back to the corresponding record in Acumatica and appear in the SO Pictures tab sub-grid visible to the CSR.
Notes Field Editable text. Saved to Acumatica automatically on blur (when the user taps elsewhere). No separate save button needed.
Delete Shows a confirmation prompt: "Delete this photo from Acumatica? This cannot be undone." On confirm, the file is deleted from Acumatica, the photo count decrements, and the user returns to the Capture screen.
Delete and Retake Deletes the photo from Acumatica immediately, then opens the camera in the same stage so the replacement photo is captured in one continuous action. No extra navigation required.
‹ Back Returns to the Capture screen without making any changes.
