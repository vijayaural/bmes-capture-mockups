Stage Label Sync - How One Change Updates Both the App and Acumatica
Admin changes label in Setup Screen
"Before" to "Intake"
►
App writes to Acumatica Config Table via API
STAGE_1 Display Label = "Intake"
►
Acumatica Pictures Tab reads config on next load
Row label shows "Intake"
►
Capture App reads config on next order load
Tab label shows "Intake"
Control IDs (STAGE_1, STAGE_2, STAGE_3) never change. Only display labels change. One source of truth: the Acumatica Configuration Table.
