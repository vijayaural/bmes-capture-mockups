Scrollable Settings Page
Accessed from the Profile tab. Orange lock badge marks sections that require administrator credentials to modify. All other sections are accessible to the logged-in user. Toggles are interactive. Save button commits all changes to the app's local configuration. Changes to Acumatica Connection or Stage Configuration take effect on the next app restart.

Setup Screen — iPad
Two-Column Configuration Layout
The iPad Setup Screen uses a two-column layout. Left column covers administrator-controlled settings: Branding, Acumatica Connection, Stage Configuration, File Settings, and Support Contact. Right column covers user-accessible settings: Capture Settings, Security, and Sync Settings, plus the Danger Zone. All toggles are interactive. The orange lock badge clearly marks sections that require administrator credentials before any change is saved. The Save All Changes button commits every modified setting in a single action, reducing the risk of partial saves.
